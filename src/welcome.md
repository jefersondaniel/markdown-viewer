# Welcome to Notes
A beautiful markdown editor for GNOME

Notes is a clean, powerful, and distraction-free markdown editor designed for your GNOME desktop. Write, organize, and enjoy your thoughts with a native experience and a touch of macOS-inspired polish.

## Features
- Beautiful, readable typography
- Seamless view and edit modes
- Organize your notes with folders
- Fast, native, and minimal

## A more focused writing experience
Whether you're jotting down quick ideas, writing documentation, or keeping a personal journal, Notes helps you stay focused on what matters most — your words.

> *"The best notes are the ones you actually write."*\
> — Notes

## Formatting at a glance

| You type | You get |
|:---------|:--------|
| `**bold**` | **bold** |
| `*italic*` | *italic* |
| `~~strike~~` | ~~strike~~ |
| `` `code` `` | `code` |
| `[link](https://www.gnome.org)` | [link](https://www.gnome.org) |

A little HTML works too: <kbd>Ctrl</kbd>+<kbd>E</kbd> switches modes, <mark>highlights</mark>, H<sub>2</sub>O, E = mc<sup>2</sup>, and <u>underline</u>.

<details>
<summary>Keyboard shortcuts</summary>

| Shortcut | Action |
|:--|:--|
| <kbd>Ctrl</kbd>+<kbd>N</kbd> | New note |
| <kbd>Ctrl</kbd>+<kbd>O</kbd> | Open a Markdown file |
| <kbd>Ctrl</kbd>+<kbd>E</kbd> | Switch between View and Edit |
| <kbd>Ctrl</kbd>+<kbd>\\</kbd> | Side by side |
| <kbd>Ctrl</kbd>+<kbd>F</kbd> | Find in note |
| <kbd>Ctrl</kbd>+<kbd>B</kbd> / <kbd>I</kbd> / <kbd>K</kbd> | Bold, italic, link (while editing) |
| <kbd>F9</kbd> | Toggle the sidebar |

</details>
